Defina a paleta completa. Cada cor tem um picker, um nome e uma descrição de uso. Os HEX atualizam automaticamente ao usar o seletor de cor.

Fundo do Design System Exportado — sem isso, o documento sai sempre escuro

Contraste & Acessibilidade — WCAG 2.1, calculado ao vivo

Texto sobre cor exige razão mínima de 4.5:1 (AA). O selo mostra o melhor par de cada cor com branco ou preto — cores reprovadas só podem ser usadas em elementos decorativos, nunca em texto.

Rampas Tonais — 10 tons por cor, gerados automaticamente

Cada cor da marca vira uma escala 010–100 (do mais claro ao mais escuro), no estilo dos grandes design systems. Os tons alimentam fundos pastel, estados de hover e seções escuras sem inventar cor nova. O selo indica se o tom aguenta texto (AAA / AA / AA-Large). Clique em um tom para copiar o HEX.

Tokens Semânticos — papéis derivados automaticamente da paleta

A cor "crua" nunca vai direto pra interface — ela alimenta tokens com papel definido: ink (texto), interface (fundos) e interactive (botões e estados). É isso que faz a LP inteira mudar trocando uma variável só. Clique no nome do token para copiar.

Hierarquia Tipográfica — gere pela escala modular ou ajuste na mão

📐 O que é escala modular? Em vez de escolher cada tamanho no chute, você define um corpo base (tamanho do texto lido) e uma razão. Cada nível acima é multiplicado pela razão — assim H2 = corpo × razão, H1 = corpo × razão², e por aí. Quanto maior a razão, mais dramático o salto entre um tamanho e o próximo.

Exportar — o Design System em 4 formatos

📘
Design System (HTML)
Documento navegável completo — a fonte de verdade da identidade. Envie ao cliente e ao time.
🧩
Tokens CSS
Variáveis prontas para colar em qualquer projeto web (:root com cores, fontes, radius e sombras).
🗂️
Tokens JSON
Estrutura de dados dos tokens — para automações, Figma plugins e integrações.
🚀
Prompt Lovable
Bloco de design tokens + diretrizes da marca pronto para iniciar a Landing Page no Lovable.
🧠
Contexto de Marca (IA)
O system prompt da marca: identidade, público, voz, tokens, fotografia e regras invioláveis em um bloco só. Cole no início de qualquer conversa com IA — texto, imagem, vídeo ou código — antes de pedir material.
💾
Salvar projeto — para editar depois
Baixa um arquivo .dsproj.json com tudo que você preencheu. Guarde-o: sempre que precisar mudar uma cor, um texto ou qualquer detalhe, é só reabrir este projeto no builder (botão "📂 Abrir projeto salvo" na 1ª etapa), ajustar e gerar de novo. Sem ele, editar depois significa refazer do zero.
