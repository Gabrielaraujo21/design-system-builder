# Design System Builder v3 — V4 Company

Ferramenta visual (um único arquivo HTML, sem instalação) para montar o design system de uma marca: cores com papel, rampas tonais, tokens semânticos, tipografia por escala modular, tom visual, movimento, contraste WCAG — e exportar o Design System completo, os tokens (CSS/JSON), o Prompt Lovable e o Contexto de Marca para IA.

## Usar agora (sem baixar nada)

👉 **Abra pelo GitHub Pages:** https://gabrielaraujo21.github.io/design-system-builder/

É só abrir no navegador e usar. Na 1ª etapa, o botão **✨ Carregar exemplo** preenche tudo com um cliente fictício para demonstração.

## Usar offline

Baixe o `index.html` (ou `Design_System_Builder_v3.html`) e abra com clique duplo. Funciona 100% offline — nenhum dado sai do seu navegador.

## Fluxo com a skill de entrevista

1. Rode a skill **[design-system-interview](https://github.com/Gabrielaraujo21/design-system-interview)** para entrevistar a marca e gerar um arquivo `.dsproj.json` (a camada de texto: manifesto, personas, tom de voz…).
2. No builder, 1ª etapa → **📂 Abrir projeto salvo** → selecione o `.dsproj.json`. Os textos já entram preenchidos.
3. Escolha cores, fontes e tokens (a parte visual, do designer).
4. Na etapa **Revisão & Export**, gere o Design System, os tokens e o **Prompt Lovable**.
5. Salve o **projeto editável** (`.dsproj.json`) para poder mudar qualquer coisa depois sem refazer.

## Editar depois

Todo Design System exportado tem um botão flutuante **✏️ Editar**: baixa o projeto para reabrir no builder (mudanças estruturais) ou permite corrigir textos direto na página.
